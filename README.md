## ▶️ Run locally

Every game is a static page. Serve a folder and open it:

```bash
cd dustline-3d   # or vice-heat-6 / vice-heat-7
python3 -m http.server 8000
# → http://localhost:8000
```

Dustline 3D needs its bundled `lib/three.min.js` (included). The Vice Heat games are fully self-contained single files.
